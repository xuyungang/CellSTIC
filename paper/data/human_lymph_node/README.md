# Human Lymph Node Spatial Multi-omics

Source: Long, Y., Ang, K.S., Sethi, R. et al. Deciphering spatial domains from
spatial multi-omics with SpatialGlue. *Nature Methods* 21, 1658–1667 (2024).
[doi:10.1038/s41592-024-02316-4](https://doi.org/10.1038/s41592-024-02316-4)

| Property | Value |
|---|---:|
| Species | Human |
| Paired spatial observations | 3,484 |
| RNA genes | 18,085 |
| ADT proteins | 31 |

The paired RNA and ADT observations have aligned spatial coordinates and
mapped cell-type annotations. The deposited ADT measurements are already
standardized: they include negative values and are not raw protein counts.
A count-style CLR transform would be inappropriate for these ADT values.
